# Implementation Plan: Last Session Card

**Branch**: `013-session-stats-card` | **Date**: 2026-04-24 | **Spec**: [spec.md](spec.md)

## Summary

Extend the existing reading-progress tracking system with explicit session start/end timestamps, enabling accurate time-on-clock, precise reading velocity, completion-per-session delta, a finish prediction, and an optional end-of-session note. Session state is persisted to the server immediately on "Start Session" tap. The `progress_history` table gains two nullable columns (`session_start_at`, `session_note`); `reading_progress` gains one (`session_start_at`). All existing rows remain valid without migration. The `LastSessionCard` component and `useLastSession` composable are updated to consume the new fields; a new `useReadingSession` composable drives the active-session lifecycle.

## Key Design Decisions

### Why `reading_progress.session_start_at` (not a new table)

`reading_progress` is the per-user-per-book mutable state record. Adding a nullable `session_start_at` here is the minimal change that:
1. Immediately persists the session start to the server (FR-011).
2. Survives app restarts without localStorage.
3. Is cleared atomically when pages are saved — no orphaned rows.
4. Requires no additional joins in the hot path.

### Why the note is a POST-save PATCH (not bundled with the save)

The history row must exist before it can be PATCHed. Bundling the note into the initial insert would require blocking the "save" confirmation on the user typing — bad UX. A fire-and-forget PATCH after row creation keeps the save flow instant and the note capture frictionless.

### Offline behaviour for Start Session

Constitution Principle IV requires that "user data MUST never be lost due to a browser refresh". An optimistic local-only session_start_at that fails to persist would be silently wrong (elapsed time shown, but server never received it — refresh loses the start time). Therefore Start Session is blocked when offline, consistent with the same constraint applied to page saves.
