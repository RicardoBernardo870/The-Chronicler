# Implementation Plan: Anki Flashcard Review

**Branch**: `026-anki-flashcard-review` | **Date**: 2026-05-06 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/024-anki-flashcard-review/spec.md`

## Summary

Add a tinder-style flashcard review experience that surfaces periodically by replacing the Word of the Day card. When the user has ≥5 lexicon entries and ≥3 days have passed since their last review, the WotD card slot is replaced entirely by an Anki prompt card. Tapping it opens a full-screen review page showing up to 20 due words as swipeable cards (swipe right = "Knew it", swipe left = "Didn't know"). Each judgement immediately updates the word's Leitner box via the existing `updateLeitner` store action. Session metadata is persisted to a new `anki_review_sessions` Supabase table (one row per user, upserted). After the last card, a summary screen is shown. Word of the Day continues unchanged.

## Technical Context

**Language/Version**: TypeScript 6 (strict)  
**Primary Dependencies**: Vue 3.5 (`<script setup>`), Pinia 3, PrimeVue 4, VueUse (`useSwipe`), Supabase JS v2, Vue Router 4  
**Storage**: Supabase PostgreSQL — new `anki_review_sessions` table; existing `lexicon_entries` (no schema change)  
**Testing**: None (per user request)  
**Target Platform**: Mobile PWA (iOS/Android)  
**Performance Goals**: Card flip/swipe animations ≤ 300ms; session load ≤ 1s  
**Constraints**: Mobile-only; review page only accessible via dashboard button; no new npm packages  
**Scale/Scope**: Up to 20 cards per session; typical lexicon < 500 entries (client-side filter is sufficient)

## Implementation Phases

### Phase A — Backend / Store Foundation

**Goal**: New Supabase table + Pinia store hydrated on app init. Word of the Day prompt condition is correct.

1. Apply `contracts/supabase-schema.sql` — creates `anki_review_sessions` with RLS.
2. Create `src/stores/ankiSession.ts`:
   - State: `lastReviewedAt: string | null`, `totalSessions: number`, `_loaded: boolean`
   - `fetchSession(userId)` — `SELECT` from `anki_review_sessions WHERE user_id = $1`; if no row, set `lastReviewedAt = null`
   - `saveSession(userId, known, unknown)` — upsert with `ON CONFLICT (user_id) DO UPDATE SET last_reviewed_at = now(), total_sessions = total_sessions + 1, known_count = known_count + $known, unknown_count = unknown_count + $unknown`
   - Computed `isDueForReview`: `lastReviewedAt === null || daysSince(lastReviewedAt) >= 3`
3. Call `ankiSessionStore.fetchSession(user.id)` in app initialisation (same location as other store hydrations — `App.vue` or `auth` watcher).

### Phase B — Session Composable

**Goal**: Pure session logic decoupled from UI.

Create `src/composables/useAnkiSession.ts`:
- Accepts `entries: LexiconEntry[]` (all lexicon entries)
- Computes `dueCards`: filter `nextReviewAt <= today`, sort by `leitnerBox` ASC, slice to 20
- Tracks `currentIndex`, `sessionKnown`, `sessionUnknown`, `isComplete`
- `onKnew(entry)`: calls `lexiconStore.updateLeitner(entry.id, 'advance')`, increments `sessionKnown`, advances index
- `onDidntKnow(entry)`: calls `lexiconStore.updateLeitner(entry.id, 'reset')`, increments `sessionUnknown`, advances index
- `onExit()`: if `sessionKnown + sessionUnknown >= 1`, calls `ankiSessionStore.saveSession(...)` before navigating away

### Phase C — Swipe Card Component

**Goal**: Reusable single-card UI with flip and swipe interactions.

Create `src/components/anki/SwipeableFlashcard.vue`:
- Props: `entry: LexiconEntry`, `bookTitle: string`
- Front face: term only + subtle "tap to reveal" hint
- Back face: definition, context sentence (if present), source book + page
- Flip: toggle `isFlipped` ref on card tap; CSS `rotateY(180deg)` with `preserve-3d` (mirrors `LexiconCard.vue` pattern)
- Swipe: `useSwipe(cardRef, { threshold: 60 })` from VueUse
  - During swipe: bind `transform: translateX(distanceX) rotate(distanceX * 0.05deg)` inline
  - On swipe end: if `|distanceX| > 80` AND card is flipped → emit `'known'` or `'unknown'` based on direction; CSS exit class triggers slide-off animation
  - If not flipped, ignore swipe (FR-009)
- Tap buttons below card: PrimeVue `<Button>` "Knew it" (green) / "Didn't know" (red) — visible only after flip; emit same events as swipe

### Phase D — Review Page & Summary

**Goal**: Full review session flow.

1. Create `src/components/anki/AnkiSessionSummary.vue`:
   - Props: `total: number`, `known: number`, `unknown: number`
   - Displays counts + motivational message
   - PrimeVue `<Button>` "Back to dashboard" → emits `'done'`

2. Create `src/pages/AnkiReviewPage.vue`:
   - Uses `useAnkiSession(lexiconStore.allEntries)`
   - Shows `SwipeableFlashcard` for `dueCards[currentIndex]`
   - On `'known'` / `'unknown'` events: calls composable handlers
   - When `isComplete`: renders `AnkiSessionSummary`
   - On summary `'done'` or back navigation: calls `onExit()` then `router.push({ name: 'dashboard' })`
   - Empty state (0 due cards): "You're all caught up!" + back button (same `wotd--done` visual language)
   - Card transition: Vue `<Transition>` with `mode="out-in"` between cards

3. Add route to `src/router/index.ts` (see `contracts/router-route.ts`):
   ```
   { path: 'anki-review', name: 'anki-review', component: () => import('@/pages/AnkiReviewPage.vue') }
   ```

### Phase E — Word of the Day Integration

**Goal**: The WotD card slot has three states. When review is due, the Anki prompt card replaces the WotD entirely. After session completion, the WotD card is restored.

Modify `src/components/dashboard/WordOfTheDay.vue`:
- Import `useAnkiSessionStore` and `useLexiconStore`
- Add computed `showAnkiPrompt`:
  ```ts
  const showAnkiPrompt = computed(() =>
    ankiSessionStore.isDueForReview && lexiconStore.allEntries.length >= 5
  )
  ```
- Add a third `v-if` branch to the `<Transition>` block (before the existing `v-else-if="entry && isPreview"` and `v-else-if="entry"` branches):
  ```html
  <!-- Anki review due — replaces WotD entirely -->
  <article v-if="showAnkiPrompt" key="anki" class="wotd wotd--review glass-surface"
           role="button" tabindex="0"
           @click="router.push({ name: 'anki-review' })"
           @keydown.enter="router.push({ name: 'anki-review' })">
    <div class="wotd__header">
      <span class="wotd__label"><i class="pi pi-clone" /> Vocabulary Review</span>
    </div>
    <div class="wotd__done-body">
      <div class="wotd__review-icon">
        <i class="pi pi-play" />
      </div>
      <div>
        <p class="wotd__done-title">Ready for review</p>
        <p class="wotd__done-hint">Tap to start your flashcard session.</p>
      </div>
    </div>
  </article>
  ```
- The `showAnkiPrompt` state takes precedence: `v-if="showAnkiPrompt"` → `v-else-if="entry && isPreview"` → `v-else-if="entry"`
- No changes to the existing WotD card states — they are untouched
- `ankiSessionStore.isDueForReview` becomes `false` once `saveSession` is called (≥1 card reviewed), causing the Transition to switch back to the WotD card automatically
